# 🚔 Chicago Crime Analysis Dashboard | Power BI

## Project Overview

Developed an interactive Power BI dashboard to analyze crime trends in Chicago, identify high-crime districts, arrest patterns, and temporal crime behavior.

The dashboard transforms raw crime data into actionable insights using interactive visualizations and KPI tracking.

---

## Dataset Source

Source: Chicago Open Data Portal

The dataset contains publicly available crime incident records including crime type, arrest information, district, time, and domestic crime indicators.

---

## Key Dashboard Features

- Crime trend analysis
- Arrest rate monitoring
- Domestic crime analysis
- Crime distribution by district
- Hourly and daily crime trends
- Crime category breakdown

## Key Insights

- Theft is the most frequently reported crime
- District 12 recorded the highest crime incidents
- Domestic crimes account for ~19.4% of total crimes
- Crime volume peaks during afternoon/evening hours
